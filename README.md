A RESTful API built using Node.js, Express.js, and SQLite to manage internship records. It supports CRUD operations, input validation, pagination, searching, and filtering.

Feature
- Create, read, update, and delete internship records.
- Input validation and error handling.
- Pagination using "page" and "limit".
- Search internships by title, company, or location.
- Filter by internship type and remote status.
- SQLite database for persistent storage.
- RESTful API endpoints with JSON responses.
